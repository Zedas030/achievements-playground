# achievements-playground

Spielwiese für GitHub-Abläufe. Hier probiere ich Pull Requests, Merges, Branches und Discussions
aus, ohne die Historie echter Projekte damit zu füllen. Inhaltlich gibt es nichts zu sehen:
[LOG.md](LOG.md) protokolliert nur, welcher Pull Request wann gemergt wurde.

Die eigentlichen Projekte:

| Repo | Worum es geht |

| [orbit-rack-demo](https://github.com/Zedas030/orbit-rack-demo) | interaktive Demo eines fiktiven Homelab-Racks |
